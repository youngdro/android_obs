## 测量方法

- **网络恢复**：直播中关闭 Wi-Fi（或开飞行模式）10 秒再打开，从打开网络到状态回到“直播中”计时。App 监听系统网络变化，恢复后会立即重连。
- **音画同步**：推流设置 → 开启“音画同步测试信号”，接收端录制 `ffmpeg -i rtmp://… -c copy rec.flv`，然后运行 `python3 tools/av_sync.py rec.flv`。长稳测试录满 60 分钟后再分析。
- **持续运行 / 性能**：直播 60 分钟后停止推流，用导出的 CSV 计算平均 `out_fps`、`dropped` 增量、`pss_mb` 曲线、`battery_c` 温升。
